# 温度湿度检测模块

## 概述

本模块使用DHT11传感器检测环境温度和湿度。

## 硬件清单

| 组件 | 型号 | 数量 |
|------|------|------|
| 主控板 | Arduino Uno/Nano | 1 |
| 温湿度传感器 | DHT11 | 1 |
| 显示屏 | 0.96" I2C | 1 |

## 技术规格

| 参数 | 温度 | 湿度 |
|------|------|------|
| 范围 | 0-50°C | 20-90%RH |
| 精度 | ±2°C | ±5%RH |
| 分辨率 | 1°C | 1%RH |

## 使用方法

1. 连接DHT11传感器
   - VCC → 5V
   - GND → GND
   - DATA → Pin 2
2. 上传程序
3. 串口监视器查看数据

## 相关文件

- `DHT11/DHT11.ino` - 主程序
- `LM35/LM35.ino` - LM35温度传感器
- `DHT11.pdf` - DHT11数据手册
