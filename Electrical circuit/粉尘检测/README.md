# 粉尘检测模块

## 概述

本模块使用GP2Y1010AU传感器检测空气中PM2.5浓度。

## 硬件清单

| 组件 | 型号 | 数量 |
|------|------|------|
| 主控板 | Arduino Uno/Nano | 1 |
| 粉尘传感器 | GP2Y1010AU0F | 1 |
| 显示屏 | 0.96" I2C | 1 |

## 技术规格

| 参数 | 数值 |
|------|------|
| 工作电压 | 5V |
| 工作电流 | 20mA |
| 检测范围 | 0-500 μg/m³ |
| 响应时间 | 0.5秒 |

## 报警阈值

| 级别 | 浓度 (μg/m³) | 说明 |
|------|---------------|------|
| 优 | 0-35 | 空气质量优 |
| 良 | 35-75 | 良好 |
| 轻度污染 | 75-115 | 敏感人群减少户外 |
| 中度污染 | 115-150 | 减少户外 |
| 重度污染 | > 150 | 避免户外 |
