# 一氧化碳（CO）监测模块

## 概述

本模块使用MQ-7传感器检测环境中的一氧化碳浓度。

## 硬件清单

| 组件 | 型号 | 数量 |
|------|------|------|
| 主控板 | Arduino Uno/Nano | 1 |
| CO传感器 | MQ-7 | 1 |
| OLED显示屏 | 0.96" I2C | 1 |
| 蜂鸣器 | 5V有源 | 1 |

## 报警阈值

| 级别 | 浓度 | 说明 |
|------|------|------|
| 安全 | < 25 ppm | 正常 |
| 警告 | 25-50 ppm | 通风不良 |
| 危险 | > 50 ppm | 可能有害 |

## 使用方法

1. 连接电路（参考原理图）
2. 上传程序
3. 预热传感器2分钟
4. 开始监测
