# 硫化氢（H₂S）监测装置

## 项目概述

本项目实现一个便携式硫化氢气体监测装置，用于检测环境中的H₂S浓度。设备具备实时监测、阈值报警、数据记录等功能，适用于下水道、污水处理、养殖场所等可能存在硫化氢泄漏的场景。

## 主要特性

- **高灵敏度**: MQ-136传感器，检测范围0.1-100ppm
- **实时监测**: 每秒更新H₂S浓度
- **多级报警**: 低/中/高浓度三级声光报警
- **数据记录**: 本地存储 + 串口输出
- **便携设计**: 电池供电，适合移动检测

## 报警阈值

| 级别 | 浓度范围 | 报警方式 |
|------|----------|----------|
| 安全 | < 10 ppm | 绿色LED |
| 警告 | 10-20 ppm | 黄色LED + 间歇蜂鸣 |
| 危险 | > 20 ppm | 红色LED + 持续报警 |
