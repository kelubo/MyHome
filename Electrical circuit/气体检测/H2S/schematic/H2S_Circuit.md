## 2. 电路连接

### 2.1 MQ-136传感器模块

```
MQ-136模块                    Arduino Uno
┌──────────────┐            ┌──────────────┐
│     VCC     │────────────│     5V       │
│     GND     │────────────│     GND      │
│     A0      │────────────│     A0       │
│     D0      │            │              │
└──────────────┘            └──────────────┘
```

### 2.2 OLED显示屏 (I2C)

```
OLED显示屏                    Arduino Uno
┌──────────────┐            ┌──────────────┐
│     VCC     │────────────│     5V       │
│     GND     │────────────│     GND      │
│     SCL     │────────────│     A5       │
│     SDA     │────────────│     A4       │
└──────────────┘            └──────────────┘
```

### 2.3 LED指示灯

```
Arduino Uno                   LED指示灯
┌──────────────┐            ┌──────────────┐
│   Pin 4     │───[220Ω]──│  绿色LED(-)  │
│   Pin 5     │───[220Ω]──│  黄色LED(-)  │
│   Pin 6     │───[220Ω]──│  红色LED(-)  │
│   GND       │────────────│  LED(+)      │
└──────────────┘            └──────────────┘
```

### 2.4 蜂鸣器

```
Arduino Uno                   蜂鸣器
┌──────────────┐            ┌──────────────┐
│   Pin 8     │───[100Ω]──│   BUZZER(+)  │
│   GND       │────────────│   BUZZER(-)  │
└──────────────┘            └──────────────┘
```

## 3. 引脚分配

| 功能 | Arduino引脚 | 说明 |
|------|-------------|------|
| H2S传感器 | A0 | 模拟输入 |
| 蜂鸣器 | Pin 8 | 数字输出 |
| 绿色LED | Pin 4 | 数字输出 |
| 黄色LED | Pin 5 | 数字输出 |
| 红色LED | Pin 6 | 数字输出 |
| 按键(静音) | Pin 7 | 数字输入 |
| OLED SCL | A5 | I2C时钟 |
| OLED SDA | A4 | I2C数据 |
