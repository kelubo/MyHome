# 硫化氢传感器校准和测试记录

## 1. 传感器特性

### MQ-136 硫化氢传感器特性

| 参数 | 数值 |
|------|------|
| 检测气体 | H₂S (硫化氢) |
| 检测范围 | 1-100 ppm |
| 标准条件 | 20°C, 65% RH |
| 加热电压 | 5.0V ± 0.2V |
| 加热功率 | ≤ 300mW |
| 负载电阻 | 可调 (推荐 10kΩ) |
| 清洁空气中阻值 | 10-200 kΩ |

## 2. 校准步骤

### 2.1 预热
- 上电后预热时间 ≥ 24小时
- 期间持续通入清洁空气

### 2.2 清洁空气校准
```cpp
// 清洁空气中校准代码
#include "MQ136.h"
MQ136 h2sSensor(A0);

void setup() {
    Serial.begin(9600);
    h2sSensor.begin();
    Serial.println("请在清洁空气中放置传感器");
    delay(60000); // 等待1分钟稳定
    h2sSensor.calibrate(1.0); // 清洁空气中校准
    Serial.println("校准完成");
}
```

### 2.3 标准气体验证
- 使用10ppm H₂S标准气体
- 验证读数在8-12ppm范围内

## 5. 常见问题

### 5.1 读数为0或偏低
- 检查传感器是否预热足够
- 检查校准是否正确
- 检查电源电压是否稳定

### 5.2 读数偏高
- 传感器可能受污染
- 尝试在清洁空气中重新校准
- 检查是否存在其他气体干扰

### 5.3 响应缓慢
- 传感器老化，可能需要更换
- 检查通风条件
