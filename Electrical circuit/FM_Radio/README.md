# FM收音机模块

## 概述

本模块使用TEA5767芯片制作FM收音机。

## 硬件清单

| 组件 | 型号 | 数量 |
|------|------|------|
| 主控板 | Arduino Uno/Nano | 1 |
| FM芯片 | TEA5767 | 1 |
| 显示模块 | I2C OLED | 1 |
| 耳机接口 | 3.5mm | 1 |

## 技术规格

| 参数 | 数值 |
|------|------|
| 频率范围 | 76-108 MHz |
| 灵敏度 | 2μV |
| 立体声分离度 | 30dB |

## 相关文件

- `library/TEA5767Radio/` - TEA5767库
- `FM_Radio.txt` - 说明文档
- `list.txt` - 物料清单
