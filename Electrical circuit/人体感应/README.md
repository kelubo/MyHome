# 人体感应模块

## 概述

本模块使用HC-SR501被动红外传感器检测人体活动。

## 硬件清单

| 组件 | 型号 | 数量 |
|------|------|------|
| 主控板 | Arduino Uno/Nano | 1 |
| 人体红外传感器 | HC-SR501 | 1 |
| LED | 5mm | 1 |

## 技术规格

| 参数 | 数值 |
|------|------|
| 工作电压 | 5V |
| 探测距离 | 3-7米 |
| 探测角度 | 120° |
| 延时调节 | 0.3-18秒 |

## 相关文件

- `Sensor/Sensor.ino` - 主程序
