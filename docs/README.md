# MyHome 文档目录

本文档目录包含传感器项目的通用文档和参考资料。

## 文件列表

### 1. 项目模板
- `项目模板.md` - 新项目文档模板

### 2. 选型指南

### 3. 故障排除

1. 创建新项目时，参考 `项目模板.md` 编写文档

3. 遇到问题时查阅 `常见问题解答.md`
4. 调试阶段参考 `调试指南.md`
