# 智能家居网关 - AirHub

## 项目概述

一个整合多种传感器数据的智能家居网关，支持数据采集、报警、远程监控和自动控制。

## 主要功能

- **多传感器整合**: 支持CO、H2S、PM2.5、温湿度等多种传感器
- **实时数据展示**: OLED本地显示 + Web远程查看
- **智能报警**: 多级报警、蜂鸣器、LED、手机推送
- **历史数据**: 本地存储 + 云端同步
- **自动控制**: 根据传感器数据自动控制设备

## 硬件清单

| 组件 | 型号 | 数量 |
|------|------|------|
| 主控 | ESP32-DevKit | 1 |
| CO传感器 | MQ-7 | 1 |
| H2S传感器 | MQ-136 | 1 |
| PM2.5传感器 | GP2Y1010AU0F | 1 |
| 温湿度传感器 | DHT11 | 1 |
| OLED屏幕 | 0.96" I2C | 1 |
| LED | RGB LED | 1 |
| 蜂鸣器 | 5V有源 | 1 |

## 报警阈值

| 传感器 | 警告 | 危险 | 紧急 |
|--------|------|------|------|
| CO | 25 ppm | 50 ppm | 100 ppm |
| H2S | 10 ppm | 20 ppm | 50 ppm |
| PM2.5 | 75 μg/m³ | 150 μg/m³ | 250 μg/m³ |

## 快速开始

### 1. 固件烧录
```bash
cd firmware/AirHub_ESP32
pio run -t upload
```

### 2. 启动服务
```bash
cd server
pip install flask flask-sqlalchemy
python app.py
```

### 3. 访问Web界面
```
http://<设备IP>
```

## API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/data` | GET | 获取所有传感器数据 |
| `/api/data/<sensor>` | GET | 获取指定传感器数据 |
| `/api/alerts` | GET | 获取报警历史 |
| `/api/control` | POST | 控制设备 |
