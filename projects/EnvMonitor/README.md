# 环境监测仪 - EnvMonitor

## 项目概述

一款便携式手持环境监测仪，可检测CO、H2S、温度、湿度等参数，适合现场检测和移动作业。

## 主要功能

- **多参数检测**: CO、H2S、温度、湿度
- **便携设计**: 手持式、电池供电
- **本地显示**: OLED实时显示数据
- **声光报警**: 超阈值声光提示
- **数据记录**: 本地存储历史数据

## 产品规格

| 参数 | 数值 |
|------|------|
| 尺寸 | 150 x 80 x 30 mm |
| 重量 | 约200g |
| 电池 | 3.7V 2000mAh锂电池 |
| 续航 | 约8小时连续工作 |
| 显示屏 | 1.3英寸OLED |
| 充电 | USB-C 5V/1A |

## 传感器配置

| 传感器 | 型号 | 检测范围 | 精度 |
|--------|------|----------|------|
| CO | MQ-7 | 20-2000 ppm | ±10% |
| H2S | MQ-136 | 1-100 ppm | ±10% |
| 温湿度 | DHT11 | 0-50°C, 20-90% | ±2°C, ±5% |

## 报警阈值

| 参数 | 警告 | 危险 |
|------|------|------|
| CO | 25 ppm | 50 ppm |
| H2S | 10 ppm | 20 ppm |
| PM2.5 | 75 μg/m³ | 150 μg/m³ |

## 使用说明

1. 长按电源键开机
2. 预热传感器2分钟
3. 开始检测
4. 查看OLED显示数据
5. 超阈值时自动报警
